{% comment %} 海角社区搜索框（海角列表页与海角搜索页共用）。 为什么不复用页头那个搜索框：页头搜索走 555 影视线路，海角社区是另一条独立线路 （帖子标题/板块/详情地址完全不同），共用一个框会让人分不清在搜哪边的内容。 用普通 GET 表单、不依赖 JS：提交后得到 /haijiao/search.html?key=关键词。 关键词走查询参数而不是路径段 —— 用户任意输入，含斜杠时路径式会产生歧义。 参数名是 key（与视图 request.GET['key'] 对齐）。 keyword 由搜索页上下文带入时会回填到输入框；列表页没有这个变量，即为空。 {% endcomment %}
